# Lagos Learn — Playable Prototype V0.1

## Included
- Procedurally generated 3D Lagos-inspired starter neighbourhood.
- Third-person movement, simple motorcycle mount/park interaction.
- Learning Centre proximity interaction.
- Three sample courses, short lessons and quizzes.
- XP and fictional game-naira rewards.
- Browser localStorage progress persistence.
- Desktop keyboard and mobile touch controls.

## Deploy to Vercel
1. Unzip this folder.
2. Upload its contents to the root of a GitHub repository.
3. In Vercel choose Add New → Project and import that repository.
4. Framework Preset: Other.
5. Build Command: leave blank.
6. Output Directory: `.`.
7. Deploy and open the generated URL on desktop and Android.

Alternative: install Vercel CLI and run `vercel` from this directory.

## Controls
Desktop: WASD / arrow keys to move; E to enter the Learning Centre when nearby; V to mount/dismount; drag mouse to rotate the camera.
Mobile: on-screen directional pad; E / ACT to interact; RIDE to mount/dismount.

## Limitations
This is a usability prototype, not production software. It has no backend, accounts, admin upload, cross-device sync, live classes, multiplayer or analytics. Course material is sample content embedded in the source. Game naira has no cash value. Three.js and fonts load from external CDNs, so testers need internet access.

## Suggested test questions
- Could you figure out how to move without help?
- Did you find the Learning Centre?
- Did the lesson feel natural inside the game?
- What was confusing, boring or slow?
- What would make you come back tomorrow?
